# WordPress comments and login

The Attackfee WordPress plugin is built for the two write surfaces most WordPress sites already have: comments and the login form. Both are on by default. Page views stay free. The plugin never gates a GET.

Upload the official zip from the [download page](/download), open Settings, then Attackfee, and leave comments and login on. The plugin is the issuer on your site: it checks the pass before those posts are accepted. It is not listed on wordpress.org.

If you also have registration or lost password open, turn those options on. Contact Form 7 and classic WooCommerce checkout are options too. The newer block checkout, XML-RPC, and application passwords are not covered.

Exact install steps are in [How to install the Attackfee WordPress plugin](/learn/wordpress/how-to-install-the-wordpress-plugin). What is on, optional, and not covered is in [What the WordPress plugin covers, and what it does not](/learn/wordpress/wordpress-what-is-covered).

## Where Attackfee fits

Start with the defaults if comments or login are the routes that cost you review time. Add options only for the forms you actually expose.

# What Attackfee is for

Attackfee is for putting a small cost on the public writes that cost a site owner something real. Use it on comment sections, contact and support forms, waitlist or newsletter signups, signup and account routes, logins, posted search, and write APIs. Leave pages, docs, and other GET requests free to read.

A visitor's browser earns a work pass in the background. An automated client does the same work, or, on attackfee.dev, pays per write over HTTP 402. The product does not score the caller, does not moderate the body of a post, and does not filter network floods.

If you want a bot score, a crawler block, or a page-view gate, look elsewhere. Those jobs are listed in [What Attackfee is not for](/learn/limits/what-attackfee-is-not-for).

## Where Attackfee fits

Start from the write surfaces you already have, mark them, and check the pass on the server. See [Who Attackfee is for](/learn/concepts/who-attackfee-is-for) and [What is Attackfee?](/learn/concepts/what-is-attackfee).

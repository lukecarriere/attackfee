# A comment thread overnight

Illustration. This is not a customer story, and it is not a report of a real incident. It describes a generic public comment thread, and it uses only the public product numbers already on the Attackfee homepage.

Imagine a comment box that stays open overnight. If posting costs the sender nothing, a script can keep sending comments while no one is at the keyboard. By morning the queue is full of junk, and every accepted post has already cost storage and review time. The thread is still there to read; the damage is in what was stored.

Now imagine the same box with Attackfee on the post. A person who is actually in the thread earns a work pass in the background. That pass covers 20 actions for 15 minutes. Overnight volume that keeps going has to earn another pass, again and again, or pay when that path is on. Reading the thread stays free.

This does not empty a queue that was already filled, and it does not stop a funded attacker who is willing to keep paying the cost. It changes the price of leaving the box open.

# Support

## Questions and bugs

Open an issue at `github.com/lukecarriere/attackfee/issues`. Please include what you ran, what you expected and what happened.

## Security problems

Don't open a public issue for a security problem. Report it privately on GitHub: `github.com/lukecarriere/attackfee/security/advisories/new`. The policy is in SECURITY.md.

## Docs

Start with the [Docs](/docs). The MCP server has its own [guide](/docs/mcp).

Try to get a write through

The form below is protected the same way your comment box or signup form would be. Fill it in and press Send. The check runs in the background while you type, and the send goes through. Then call the same endpoint the way a script would, with no pass, and watch the server refuse it.

Contact

Protected as a write.

Accepted · 200

Without a pass

The same endpoint, called with no pass. This is what an automated client gets on its first try.

$ curl -X POST https://attackfee.dev/demo/contact -d "message=hi"
403  {"error": "attackfee_required", "challenge": { ... }}
Rejected · 403

As an AI agent

Send the same request with the Attackfee-Client: agent header and the server answers 402 with a price and a link to a work challenge. The agent can pay for one write or do the work and earn a pass for 20. A write costs under a cent; current prices are at /v1/price.

$ curl -X POST https://attackfee.dev/demo/contact -H "Attackfee-Client: agent" -d "message=hi"
402  {"error": "payment_required", "challenge_url": "/v1/challenge?...", ... }

This demo checks writes only. A browser earns a pass with background work. An automated client can pay over HTTP 402 or do the same work. What you type is checked and then thrown away: it is never stored, echoed, emailed or logged.

# Security policy

## Reporting a vulnerability

Report it privately through GitHub: https://github.com/lukecarriere/attackfee/security/advisories/new

Please don't open a public issue, pull request or discussion for a security problem.

Include what you ran, what you expected, what happened, and the commit or version. We reply on the advisory.

## Scope

The code in this repository and the site at https://attackfee.dev. Attackfee does not claim to stop a funded attacker or to filter network floods (see the README "What it doesn't do"), so a report that work can be bought on rented GPUs is expected behavior, not a vulnerability.

## Supported versions

The latest release on npm and the main branch.
